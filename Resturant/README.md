# 🍽️ Restaurant Food Ordering Website

## 📌 Project Overview

The Restaurant Food Ordering Website is an intermediate-level frontend web development project created using HTML5, CSS3, and JavaScript.

This website allows customers to explore different food items, view prices, add food products to their shopping cart, manage quantities, calculate the total bill, and place a sample order.

The website provides a simple, attractive, and user-friendly interface for online food ordering.

## 🚀 Features

- Responsive homepage.
- Navigation bar with Home, Menu, About, Contact, and Cart.
- Food menu with images and prices.
- Chicken Biryani, Pizza, Burger, Pasta, Noodles, and Ice Cream.
- Add food items to cart.
- Increase and decrease food quantities.
- Remove items from the shopping cart.
- Automatic subtotal and total calculation.
- Delivery charge calculation.
- Customer checkout form.
- Order confirmation message.
- About Us section.
- Contact Us section.
- LocalStorage support.
- Mobile-friendly responsive design.

## 🛠️ Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, layouts, animations, and responsive design.
- **JavaScript:** Shopping cart, quantity management, and calculations.
- **LocalStorage:** Saving cart information in the browser.
- **Visual Studio Code:** Code editor.

## 💻 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three source files are in the same folder.
4. Open `index.html`.
5. Install the Live Server extension.
6. Right-click on `index.html`.
7. Select Open with Live Server.
8. The website will open in your browser.

## 🛒 How to Use

1. Open the Restaurant Food Ordering Website.
2. Navigate to the food menu.
3. Select your favourite food item.
4. Click the Add to Cart button.
5. Open the shopping cart.
6. Increase or decrease the quantity.
7. Remove unwanted food items.
8. View the automatically calculated bill.
9. Click Proceed to Checkout.
10. Enter customer details and place a sample order.
