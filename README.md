# web-project-html-and-css

Login and Signup Page

Project Overview

The Login and Signup Page is a beginner-friendly web development project created using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface where users can enter their details in login and registration forms.

Features

- Simple and clean user interface
- Login form with name, email, and password fields
- Signup form with full name, email, and password fields
- Navigation between Login and Signup sections
- Basic form validation
- Responsive layout for different screen sizes
- Interactive buttons using JavaScript

Technologies Used

- HTML5 – Structure of the web page
- CSS3 – Styling, colors, layout, and responsive design
- JavaScript – Form submission interactions

Project Structure

LoginSignupProject/
│
├── index.html
├── script.js
└── README.md

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure "index.html" and "script.js" are in the same folder.
4. Open "index.html" in your browser, or use the Live Server extension in VS Code.
5. Try the Login and Signup forms.

- Implementing basic client-side form validation
