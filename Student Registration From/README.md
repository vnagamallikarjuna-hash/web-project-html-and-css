Student Registration Form

Project Overview

The Student Registration Form is a beginner-friendly web development project built using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for collecting student information through an online registration form.

This project helps beginners understand form creation, webpage styling, client-side validation, and JavaScript event handling.

Features

- Simple and user-friendly interface
- Student full name input field
- Email address field
- Mobile number field
- Gender selection
- Course selection
- Required field validation
- JavaScript form validation
- Interactive form submission
- Responsive design for different screen sizes

Technologies Used

- HTML5 – Creates the structure of the registration form.
- CSS3 – Styles the form using colors, spacing, layouts, and responsive design.
- JavaScript – Adds form validation and interactive functionality.

Project Structure

StudentRegistrationForm/
│
├── index.html
├── style.css
├── script.js
└── README.md

File Description

- index.html – Contains the structure and input fields of the student registration form.
- style.css – Defines the colors, fonts, spacing, and overall appearance of the form.
- script.js – Handles client-side validation and form submission interactions.
- README.md – Contains project documentation, features, technologies, and setup instructions.

How to Run the Project

1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open "index.html" in your web browser, or use the Live Server extension.
5. Enter the student details in the registration form.
6. Submit the form to test its validation and JavaScript functionality.
